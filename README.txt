LTD Concepts website
====================

Open index.html in a browser.

Before publishing:
- Replace the three contact-number placeholders with the numbers from the flyer.
- Replace the Facebook # links with the real Facebook page.
- Replace placeholder Unsplash service/hero images with approved LTD Concepts images.
- Replace the rough quote rates in the JavaScript with your actual pricing.
- Replace the Durban map iframe with the preferred exact business location if needed.

The page uses CDN-hosted Tailwind CSS, GSAP/ScrollTrigger, Font Awesome and Google Fonts, so an internet connection is needed when viewing it unless those dependencies are downloaded/localized.
